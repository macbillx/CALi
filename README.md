# CALi · Calibration Masters

A static browser app for the Calibration Masters certificate register. Includes the searchable certificate database, data quality review, editable records, printable certificate preview, and local JSON backup import/export.

## Run and publish

Open `index.html` in a modern browser. To publish, upload the contents of this folder to the repository root and enable GitHub Pages.

## Data handling

The app stores edits in browser local storage; records do not sync across devices. The starter data includes only the two incomplete source records (rows 19 and 20) needed to demonstrate Data Quality review. Review client and project information before publishing this repository publicly. Use JSON backup export to move register data between browsers.
